# Configuration Guide

## Setup Instructions

### 1. Main Configuration

Copy the example configuration file and modify it:

```bash
cp config.yaml.example config.yaml
```

Edit `config.yaml` and update:
- `auth.password`: Your admin password
- `singbox.config_dir`: Absolute path to singbox configs directory
- `singbox.log_dir`: Absolute path to logs directory
- `database.path`: Absolute path to database file
- `mikrotik.*`: Your MikroTik router credentials (if enabled)

### 2. Sing-box Node Configuration

Node configurations are created automatically by the web UI, but you can also manually create them:

```bash
cp singbox/node.json.example singbox/node_1.json
```

Edit the node configuration with your proxy server details:
- `server`: Your proxy server address
- `server_port`: Your proxy server port
- `uuid`: Your VLESS/VMess UUID
- TLS/Reality settings as needed

### 3. Security Notes

⚠️ **Important**: Never commit actual configuration files to git!

The following files are ignored by git:
- `configs/config.yaml`
- `configs/singbox/*.json`

Only `.example` files should be committed to the repository.

### 4. Directory Structure

```
configs/
├── config.yaml.example     # Main config template
├── config.yaml            # Your actual config (git-ignored)
├── singbox/
│   ├── node.json.example  # Node config template
│   ├── node_1.json       # Auto-generated by UI (git-ignored)
│   ├── node_2.json       # Auto-generated by UI (git-ignored)
│   └── ...
└── README.md             # This file
```
